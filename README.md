# جدولي (Jadwali)

موقع ويب لعرض الجدول الدراسي الأسبوعي بشكل تفاعلي مع التعرف التلقائي على الوقت والتاريخ لتحديد الحصة الحالية والحصة القادمة والوقت المتبقي.

## الملفات المرفقة
- `index.html`: الصفحة الرئيسية للموقع وشاشة البداية المتحركة (رسم الشعار).
- `style.css`: تنسيقات الهوية البصرية (البرتقالي `#f56818` مع الأبيض والكحلي الغامق) والوضعين الفاتح والداكن.
- `script.js`: منطق حساب الحصة الحالية والقادمة والعد التنازلي اللحظي.
- `logo.png`: شعار الموقع المعتمد بخلفية شفافة بالكامل.

## طريقة الرفع على GitHub Pages
1. ارفع جميع الملفات (`index.html`, `style.css`, `script.js`, `logo.png`) مباشرة في المجلد الرئيسي (Root) للمستودع.
2. توجه إلى **Settings** ثم **Pages** وفعّل النشر من فرع `main`.
